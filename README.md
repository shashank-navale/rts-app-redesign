# RTS App Redesign

A one-page product and UX case study: redesigning Gainesville's RTS transit app around the moment riders stop trusting it. It covers rider interviews, needs and personas, NUF prioritization of 24 ideas into the HeadsUp concept, and HeadsUp's wireframes and wireflow.

**Live:** https://shashank-navale.github.io/rts-app-redesign/

## Preview locally

```bash
python3 -m http.server 8000
```

Then open http://localhost:8000/.

## Checks

```bash
python3 -m unittest discover -s tests -v
```

Plain HTML, CSS and a little vanilla JS: no build step.
